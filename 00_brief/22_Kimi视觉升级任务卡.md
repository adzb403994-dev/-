# Kimi 视觉升级任务卡（V1）

## 一、背景

《数字守楼人·活态客家魂》内容框架、财务口径、共益机制已经稳定，当前版本 `v7.6` 共 77 页。  
问题不在文字，在**视觉精细度**：信息图版大量用卡片/表格代替真正的图形，缺地图、剖面、旅程、瀑布、趋势、组织图；章首模板重复；AI 图像建筑形制不统一。

目标：在不改内容、不改数字、不改 77 页结构的前提下，把视觉从"排版整齐的报告"提升到"可参赛的作品集"。

## 二、输入文件

- 当前 PDF：`成果\数字守楼人_v7.6_图片校正版_A4.pdf`
- 设计源文件：`06_项目版本\v2.0\design\style.css`、`v4.0_design.html`
- 数据：`Kimi 的产出\T2.1_基准方案\T2.1_基准方案.xlsx`、`T2.1_关键数据.csv`
- 图像：`06_项目版本\v2.0\images\`
- 内容稿：`06_项目版本\v2.0\v4.0_A/B/C/D.md`

## 三、锁定项（不可改）

- 不改任何数字、结论、财务口径、共益比例；
- 不改 77 页结构、七章 + 四附录；
- 不改主命题："把体验请出土楼，把收益留给村民"；
- 纸张 A4（210×297mm）、正文字体 Noto Serif SC / Noto Sans SC；
- 所有图必须可打印、可缩放、标注数据来源；
- 土楼图像必须是**彼此独立的单座圆环形土楼**，不得连排、不得共用墙。

## 五、委托给 Kimi 的 5 个交付物

### 交付 1：视觉诊断 + 对标（1 份，≤15 页）

- 选 3 个对标：全国赛优秀作品/优秀文旅策划案/优秀数据可视化；
- 逐页标出"可保留/可优化/必须重做"；
- 给出 10 条以内、可执行的视觉升级原则。

### 交付 2：艺术指导（1 份）

- 色彩：赭石、深绿、米色为主，给出色值/使用比例；
- 字体：标题/正文/数字/注释层级；
- 网格：A4 版心、栏宽、边距、图版留白；
- 图标：一套 12—16 个线性图标（土楼、溪流、村民、账本、审批、监测等）；
- 图形语言：地图、剖面、流程、瀑布、甘特、组织的统一画法；
- 图像风格：AI 场景图统一光线/色调/建筑形制，禁止连排土楼。

### 交付 3：6 张核心图重做（最重要）

用 SVG / HTML+CSS / 300dpi PNG 交付，必须可编辑、可印刷：

1. **区位与资源地图**：南溪在永定/土楼南线；西片—南江—南中—新南；2 座世遗 + 1 处省保 + 3 个传统村落 + 112 户。
2. **三个距离剖面**：本体 → 5m → 15.2m → 62m；标出本体保护范围、建设控制地带、环境协调区；不是卡片，是剖面图。
3. **空间布局与产品旅程**：一溪两岸、三区多点；一日/两日/三日线路；游客动线。
4. **资金结构与分配瀑布**：4170 万 = 1018 + 1010 + 1159 + 983；公司只投 1159 万；资金峰值 992 万、最低现金 -22.7 万。
5. **五年趋势与现金**：Y1—Y5 收入/净利/现金；Y4 收入 1421 万、净利 76 万、净利率 5.7%；不画"高增长"假曲线。
6. **治理与共益**：股东会/董事会、共益理事会 9 人、文化顾问 7—9 人；保底→分成→共益三层；65/35、60/40、70/20/10、6%、1%+20%。

### 交付 4：图表规范（1 份）

- 什么数据用什么图：趋势用折线、结构用瀑布/堆叠、比例用条形、情景用 tornado、流程用箭头；
- 统一字号、线宽、标注、来源行；
- 不许用 3D、渐变、阴影、花哨配色；
- 每张图必须有"一句话结论"。

### 交付 5：12 页路演视觉模板（可选，但强烈建议）

- 16:9，和 PDF 同一套视觉语言；
- 一页一个判断，图占 ≥50%；
- 可直接套 12 页大纲。

## 七、验收标准

1. 数字、结论、口径 100% 与 v7.6 一致；
2. 图在 A4 100% 打印尺寸下，最小字号 ≥7pt，线宽 ≥0.5pt；
3. 每张图有标题、单位、来源、一句话结论；
4. 三个距离/空间图必须能看出"本体—建控—环境协调"三层关系；
5. 土楼图形必须是单座圆环，不得连排；
6. 能嵌入现有 Paged.js / CSS 体系，不破坏 77 页分页。

## 八、建议节奏

- 第 1 步：先交"视觉诊断 + 2 张样图"（区位地图 + 三个距离剖面），我们确认方向；
- 第 2 步：再交其余 4 张核心图 + 图表规范；
- 第 3 步：Lead 集成进 PDF，做一次 A/B 对比，再决定是否替换全部图版。

## 九、边界

- Kimi 只做视觉与图形，不改正文、不改财务、不改合规表述；
- 所有数字以 `T2.1_关键数据.csv` 与 v7.6 为准；
- 不确定的图形关系先提问，不要自行编造地理/建筑/审批关系。
